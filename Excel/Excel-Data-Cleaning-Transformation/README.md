# Excel Data Cleaning & Transformation

## Project Overview

A practical Excel data-cleaning and transformation project focused on turning messy and inconsistent business data into cleaner, more consistent, and analysis-ready tables.

The project documents 22 practical scenarios using common business examples such as sales records, employee names, order IDs, dates, and contact numbers.

## Project Objectives

- Clean and standardize inconsistent spreadsheet data
- Handle missing values and calculation errors
- Restructure unorganized records into usable tables
- Standardize names, dates, and contact information
- Apply Excel functions and features to solve practical data-quality problems
- Prepare datasets for analysis, reporting, filtering, and further processing

## Project Scope

- 22 practical data-cleaning scenarios
- Data-quality and error handling
- Data standardization
- Data restructuring
- Text, date, and contact-number processing
- Practical business-oriented Excel solutions

## Key Areas Covered

### 1. Data Quality & Error Handling

- Handling calculation errors with IFERROR
- Preserving long order IDs
- Splitting names using Flash Fill
- Parsing combined business details
- Removing blank rows
- Filling missing values

### 2. Data Standardization

- Standardizing mixed date formats
- Identifying and removing duplicates
- Clearing inconsistent formatting
- Cleaning names with TRIM and PROPER
- Replacing unwanted characters

### 3. Data Restructuring

- Reshaping unstacked sales records
- Restructuring country details
- Reordering month columns
- Changing text case
- Combining name fields

### 4. Text, Date & Contact Transformation

- Extracting name components
- Creating dynamic text outputs
- Reversing name order
- Generating email IDs
- Extracting date components
- Adding country codes to phone numbers

## Practical Examples

### Error Handling

Used IFERROR to prevent invalid calculations from producing disruptive errors.

### Name Cleaning

Used TRIM and PROPER to remove unnecessary spaces and standardize capitalization.

### Date Standardization

Applied a consistent `dd-mmm-yyyy` format to create readable and consistent date fields.

### Data Restructuring

Used Flash Fill and dynamic-array techniques to transform unstructured records into analysis-ready layouts.

### Contact Standardization

Combined country codes and phone numbers into standardized international-format contact values.

## Outcome

This project demonstrates practical spreadsheet problem-solving, data-quality awareness, and the ability to transform messy business data into cleaner structures suitable for analysis and reporting.

## Project Type

Practical Excel learning project developed through business-oriented data-cleaning and transformation scenarios.
