Retail Sales Performance Dashboard
Project Overview
This Excel-based retail sales analysis project focuses on evaluating sales performance, target achievement, regional performance, and delivery efficiency. The dashboard transforms transactional sales data into a clear management-level view for identifying strong-performing and underperforming regions.
Business Objectives
•	Analyze overall sales and order performance
•	Compare actual sales with sales targets
•	Evaluate regional performance
•	Identify regions with stronger or weaker target achievement
•	Analyze average delivery performance across regions
•	Present key findings through an interactive dashboard

Key Insights
•	Barishal recorded the highest sales among the regions.
•	Dhaka achieved the strongest target achievement ratio at approximately 94.34%.
•	Rangpur recorded the lowest target achievement ratio at approximately 86.96%.
•	Rangpur also showed the highest average delivery time among the regions.
Dashboard
The dashboard provides a consolidated view of sales performance and regional comparisons, helping users quickly identify trends, performance gaps, and areas requiring attention.
